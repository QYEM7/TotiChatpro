# T42 in-app user support flow

Existing TotiChat app has an in-profile support entry; the approved HTML,
15 seats, animations, gifts and mic controls remain identical.
Users submit real authenticated support tickets, including host agency
applications with required agency name/contact, and see only their own
SQL RLS-protected ticket status. RPC creation is rate-limited/idempotent.
Customer service staff queue and reviews use restricted server RPCs
assigned only by Owner; no automatic host agency approvals.
An offline/undeployed service shows a real failure, never a mock success.
No production tickets created by tests. Employee-facing management UI,
notifications, service standards and appeals remain T42 work items.
