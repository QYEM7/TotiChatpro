### Banner data contract

| Column | Meaning |
| --- | --- |
| `id` | UUID generated by server |
| `title` | Real visible caption (1–120 characters) |
| `image_url` | Public HTTPS image URL (store design artwork in an authorized bucket) |
| `status` | `draft`, `published`, or `archived` |
| `sort_order` | Smaller number displays first |
| `starts_at`, `ends_at` | Optional publication period (UTC timestamps) |
| `link_kind` | `none`, `screen` or `external` |
| `link_target` | An allowlisted internal screen ID or verified HTTPS URL |

**Security:** The SQL enables RLS, exposes only active published rows, and denies direct anonymous/authenticated mutations. The frontend accepts HTTPS media and link URLs only, escapes titles before HTML rendering, rejects unknown internal routes, caps to 12 visible slides, reports load errors clearly, and never substitutes fake slides on failure.
