# TotiChat — new Flutter client, v1 foundation

This is a **separate new implementation** under `rebuild/flutter-v1`.
The rejected Reborn frontend is **not imported, compiled, or reused**. The Falcon logo
is copied from the existing repository asset. No Supabase schema or user balances
are modified by this commit.

## What actually works in source

- Google-only OAuth using `supabase_flutter` with PKCE.
- Real public room list and published home banners (hidden when none).
- Server-RPC room creation, join/leave, 15-seat membership, seat selection, server messages.
- LiveKit audio connection with JWT granted by the existing verified Staging Edge Function.
- Microphone permission and server-backed mute authorization; no local role spoofing.
- Server-read profile, admin-assigned ID and wallet coins/diamonds/silver.
- Network errors surfaced explicitly. No fake balance, mocked home rooms or placeholder ad content.
- Original Falcon logo and new responsive light Flutter theme.

## What is **NOT** ready

This is an initial implementation, not a production release. The detailed
gift box, full CP/VIP flows, music synchronisation, agencies, wallet transactions,
administration, DM and full moderation screens are still to be built.
Android Google login and 2-phone LiveKit audio are not yet proven on physical devices.
The new OAuth redirect must be configured in **Staging** Auth settings.
No APK/AAB is built automatically, and production is never connected.

## Setup

Install Flutter stable with Dart >=3.10. From `flutter_app/`:

```sh
flutter create --platforms=android --org com.totichat --project-name totichat .
flutter pub get
flutter analyze lib test
flutter test test/architecture_test.dart
flutter run --dart-define=SUPABASE_PUBLISHABLE_KEY=<STAGING_PUBLIC_KEY>
```

Use ONLY the **publishable/anon** key from Staging. A public key is client-safe,
but **service_role, private keys, LiveKit secrets and Admin keys must never
enter the client**.

In Supabase Staging **Authentication > URL Configuration > Redirect URLs**, the
Owner must add `com.totichat.next://auth/callback`. This is intentionally
not done in the live Production project. Test Google OAuth on an actual Android
device before trusting any login.

The underlying new Android applicationId generated by Flutter is
`com.totichat.totichat`. Register the correct package, signing certificate and
deep-link redirect when packaging a release.

## Safety guarantees

- `AppConfig` only permits `rziaedugbdwefbefcxjt`.
- Financial credits/charges are never implemented as client table writes.
- Existing RPC functions require an authenticated actor; all authorization stays
  on the backend.
- No production migration or branch merge.
- No user-facing fake data.
