# TotiChatpro — Approved TotiChat Visual Master

**User-visible app name:** TotiChat (without `pro`).

## Design authority

This repository is a clean rebuild. The approved interactive UI/UX master is `index.html`, identical to the previously approved standalone visual review except that its image paths have been made repository-local. `reference/approved-original.html` is the original, unmodified master.

Source at approval: `jsjsnsnsnsn0-pixel/TotiChat`, branch `preview/visual-review-20261009`, file `visual-review/index.html` (blob d4a4b03565f26657e9279f93b31511d29164caa7).

**Do not replace the layouts, logos, visual identity, or controls with approximations.** Obtain visual sign-off for this independent copy before implementing live frontend workflows, backend integrations, Android wrapping, or production finance.

**Important:** The visual master is an interactive demonstration with placeholder users, balances and actions. It is not a real working application. Until a backend is built, all its data and actions are demonstration-only.

## Viewing

Open `index.html` on a local HTTP server or publish it as a static site. To deploy on GitHub Pages, enable Pages for the repository on the `main` branch and `/ (root)` path, or configure GitHub Actions deployment.

Images are included under `assets/images/` so this new repo is independent of the previous repository.
